## C. LinkedIn project description

**Social Media Privacy Risk Assessment Framework** — Python · FastAPI · SQLite · React + Vite ·
Recharts · pytest

I built a defensive cybersecurity framework that helps people understand how exposed their
social-media presence really is — without scraping, tracking or profiling anyone.

The tool asks 58 self-reported questions across 10 privacy categories (profile visibility,
personal information, location privacy, posts & content, connections, tagging, account security,
third-party apps, social engineering and digital footprint) and converts them into a deterministic
0–100 risk score with a full contribution breakdown. It then generates severity-rated findings,
prioritised recommendations (IMMEDIATE / IMPORTANT / GOOD PRACTICE), an exportable HTML/PDF report
and a "what if I improve my settings?" simulator — the synthetic demo profile drops from 84.5
(CRITICAL) to 28.1 (MODERATE) once the improvements are applied.

It also implements a second, complementary 8-dimension exposure rubric (PII 25 · geolocation and
EXIF 20 · children/minors in media 15 · workplace and school disclosures 10 · weak privacy
settings 10 · linkage risks 10 · handle correlation 5 · third-party trackers 5, capped at 100),
which can score either the questionnaire or a voluntarily supplied synthetic profile/posts export.
I kept the two models deliberately separate and documented that they are complementary rather
than equivalent.

What I care about most in this project is the privacy engineering: the application never asks for
a phone number, e-mail address, birth date or password — only whether such information is publicly
visible — and the database stores nothing but scores, finding types and timestamps. That claim is
verified by automated tests that scan the raw database file and every generated report for
sensitive patterns. 76 tests run end to end, and the result matrix is generated by the test run
itself rather than written by hand.

Also included: a defensive threat model, a privacy risk matrix, a social-engineering awareness
module (conceptual only — no attack content), a 1,200-record synthetic dataset and a
Privacy-by-Design implementation map.
